# Test guide: round 2

Status: **draft for Zachary to approve.** Don't use it with testers until it's approved. Round 1's guide is in the project's history.

## What round 2 tests

The same question as round 1: can a small business owner tell **what to push on** and **what could cost them the most**? Round 2 also checks the changes round 1 asked for: the "How this works" page, every section sorted into tiers, the asks with their reasons, and the version names.

Each tester sees the page as it is: "How this works" first, then **Lease text first**, **What to ask first** and **Risk summary first**, in the order the buttons show.

## Before each session

- **Use the class laptop** and the main link: https://zacharybhattacharjee.github.io/clause-and-effect/. Add the tester's code to the end, such as `?t=R1`, so it shows in the footer. Press **Cmd+Shift+R** once, so the page isn't an old copy.
- **Have the lease PDF on the desktop.** The round 2 page has no sample button, so the PDF has to be uploaded. You can upload it yourself before the tester sits down, or let them do it and watch how it goes.
- **The blank form has gaps** where the numbers go, and the page shows "(see the lease)" where a number belongs. If a tester asks, say: "The lease would have a number there."
- **Paper:** one copy of the note sheet per tester, with a code such as R1 at the top instead of a name.
- **Roles:** if you can, have a classmate run the session while you take notes.

## What to say at the start

> Thanks for helping. We're testing a prototype, not you, so there are no wrong answers. If something is confusing, that's what we need to know.
>
> The tool reads a lease and shows it three ways. Please think out loud as you go.
>
> We aren't recording anything or saving your name. I'm only taking notes on paper, under a code. This is a class project, not legal advice. You can stop at any time. Is that OK?

Then let the tester read "How this works" at their own pace, and choose the first version from its buttons.

## During each version

Let the tester read for up to **4 minutes**, then ask the questions below. Ask the same first three questions for every version. The fourth is different each time, so nobody gets the same fact question twice.

1. **Cost:** "Which section could cost your business the most? Why?"
2. **Push on:** "Pick one thing you'd ask the landlord to change before you sign. What would you ask for, and why could you ask for it?"
3. **Ease:** "On a scale of 1 to 7, how easy was it to work that out? 1 is very hard, 7 is very easy."
4. **One fact question:**
   - **After Lease text first:** "If you rent the space to someone else, do you still owe the rent?"
   - **After What to ask first:** "If you pay rent late, how long do you have before the landlord can act?"
   - **After Risk summary first:** "Is there a limit on how much the building-cost charge can go up?"

Then the tester switches to the next version with the buttons at the top.

**If they're stuck,** use only neutral prompts:
- "What are you looking for?"
- "What would you do next?"
- "Take your time."
- "Tell me more about that."

Never point to the answer, and never say whether an answer is right.

## After all three versions

1. "Which version would you want to use before signing a real lease? Why?"
2. "Did the 'How this works' page help? Was anything on it confusing?"
3. "What do the tier labels mean to you?" (Ask before they click one, if they haven't.)
4. "If you wanted help with this lease, who would you ask?"
5. "Is there anything you'd want this to do that it doesn't?"

Then thank them, and close the browser tab, which clears the lease.

## What to write down

Use one note sheet per tester:

| | Lease text first | What to ask first | Risk summary first |
| --- | --- | --- | --- |
| Cost: which section, and their reason | | | |
| Push on: what they'd ask for, and why | | | |
| Ease (1 to 7) | | | |
| Fact question answer | | | |
| Where they hesitated or got stuck | | | |
| Exact words worth quoting | | | |

Also note whether they:
- read "How this works", or skipped it
- clicked a tier label, without being told
- tapped an underlined word
- opened "Words to propose"
- used "Whole lease, in order"
- used the "On this page" list
- found "What to do next" at the end, or printed it
- found "Sections the tool couldn't sort", and what they made of it

**For the observer only** (don't share with testers), these are the answers that match the page and the lease:

| Question | Matches the page |
| --- | --- |
| Cost | It depends on the tiers set in the workbook before the session. If no tiers are set, every section shows "Tier not set" and the page doesn't rank them, so write down the tester's reasoning instead. |
| Rent the space to someone else | Yes, you still owe the rent. Section 13 says so, and the page explains it. |
| Pay rent late | 10 days after the landlord's written notice. That's in section 19's own words. The page's explanation shows "(see the lease)" in place of the number. |
| Building-cost limit | No, the lease sets no limit (section 6B). The page doesn't explain 6B yet, so the answer is only in the lease's own words. |

## Reading the results

- **Later versions get a head start.** Everyone sees "How this works" and the first version before the others, so later versions may feel easier just because the lease is familiar by then.
- **Five or six testers is enough** to find most of the confusing parts. It isn't enough to prove one version is better. Say what you saw, such as "4 of 6 used the tier labels", not that a version "works".
- **Never write down names.** Use only the codes on the note sheets.

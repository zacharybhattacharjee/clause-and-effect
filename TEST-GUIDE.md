# Test guide: round 1

Status: **draft for Zachary to approve.** Don't use it with testers until it's approved.

## What round 1 tests

The question: can a small business owner tell **what to push on** and **what could cost them the most**, and does one version make that easier?

Each tester uses the page as it is: Version 1, then 2, then 3, all showing the same three clauses (building costs, subletting, late rent).

## Before each session

- **Use the class laptop** and the live link: https://zacharybhattacharjee.github.io/lease-reader/ Press **Cmd+Shift+R** once, so the page isn't an old copy.
- **Upload the lease PDF before the tester sits down.** The sample button has no lease text yet, so Version 1 would show gray boxes. Keep the PDF on the desktop.
- **The blank form has gaps** where the numbers go, such as "…percent of any increase…". If a tester asks, say: "That's a blank the landlord fills in." Say nothing more.
- **Paper:** one copy of the note sheet per tester. Write a code at the top, such as R1, R2, R3, instead of a name.
- **Roles:** if you can, have a classmate run the session while you take notes. People who built a design tend to help testers without meaning to.

## What to say at the start

> Thanks for helping. We're testing a prototype, not you, so there are no wrong answers. If something is confusing, that's what we need to know.
>
> You'll see the same parts of a lease shown three ways. Please think out loud as you go.
>
> We aren't recording anything or saving your name. I'm only taking notes on paper, under a code. This is a class project, not legal advice. You can stop at any time. Is that OK?

Then let the tester start on Version 1.

## During each version

Let the tester read for up to **3 minutes**, then ask the questions below. Ask the same first three questions for every version. The fourth is different each time, so nobody gets the same fact question twice.

1. **Cost:** "Which of these three could cost your business the most? Why?"
2. **Push on:** "Pick one thing you'd ask the landlord to change before you sign. What would you ask for?"
3. **Ease:** "On a scale of 1 to 7, how easy was it to work that out? 1 is very hard, 7 is very easy."
4. **One fact question:**
   - **After Version 1:** "If you rent part of the space to someone else, do you still owe the full rent?"
   - **After Version 2:** "If you pay rent late, how long do you have before the landlord can act?"
   - **After Version 3:** "Is there a limit on how much the building-cost charge can go up?"

Then the tester switches to the next version with the buttons at the top.

**If they're stuck,** use only neutral prompts:
- "What are you looking for?"
- "What would you do next?"
- "Take your time."
- "Tell me more about that."

Never point to the answer, and never say whether an answer is right.

## After all three versions

1. "Which version would you want to use before signing a real lease? Why?"
2. "Was anything confusing, or did any word stop you?"
3. "If you wanted help with this lease, who would you ask?" (This tells you whether a line about free help, such as the CBC, is needed.)
4. "Is there anything you'd want this to do that it doesn't?"

Then thank them, and close the browser tab, which clears the lease.

Use one note sheet per tester:

| Cost: which clause, and their reason | | | |

| Ease (1 to 7) | | | |

| Where they hesitated or got stuck | | | |
| Exact words worth quoting | | | |

Also note:
- whether they tapped an underlined word in Version 2 or 3, without being told
- whether they found "What to do next" at the end
- whether they pressed "Upload a different lease" by mistake
- their answers to the four closing questions

**For the observer only** (don't share with testers), these are the answers that match the page:

| Question | Matches the page |
| --- | --- |
| Cost | Late rent and other defaults. It's ranked 1 on the page. A tester who reasons their way to another answer isn't "wrong". Write down why. |
| Rent part of the space | Yes, you still owe all the rent (section 13). |
| Pay rent late | 10 days after the landlord's written notice (section 19). |
| Building-cost limit | No, the lease sets no limit (section 6B). |

## Reading the results

- **Versions 2 and 3 get a head start.** Everyone reads Version 1 first, so by Versions 2 and 3 they already know the three clauses. Some of what looks easier in 2 and 3 is just reading the same clauses again. Keep that in mind before saying one version is better.
- **If you want a fairer comparison later,** the page can show the versions in a different order for each tester, using a link setting. It's there whenever you want it.
- **Five or six testers is enough** to find most of the confusing parts. It isn't enough to prove one version is better. For your presentation, say what you saw, such as "4 of 6 found the highest-risk clause in Version 3", not that a version "works".
- **Never write down names.** Use only the codes on the note sheets.
